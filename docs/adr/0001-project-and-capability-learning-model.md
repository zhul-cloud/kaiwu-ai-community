# ADR 0001：采用项目驱动与能力晋级的双维度学习模型

## 状态

已决定

## 背景

社区的目标是帮助成员真正使用 AI 完成工作和项目。只按课程顺序学习，容易出现学完概念却无法交付结果；只按项目推进，又可能导致能力结构不完整。

## 决策

采用两个互相配合的维度：

1. 以真实项目驱动学习。项目需要明确场景、目标、约束和验收标准，学习内容根据项目需要组合。
2. 以能力模型支持晋级。成员通过阶段练习和项目验收，逐步从环境使用者成长为 Agent 构建者。

第一期以 Claude Code 为主，面向不懂代码、希望提升工作效率的职场人，周期为 14 天，结业标准是独立完成一个可运行、可交付的小项目。第一期属于培训验证期，先验证课程内容、项目路径和用户需求；长期陪跑作为后续产品形态逐步发展。

课程使用 `llm-wiki` 作为综合案例，展示知识组织、上下文管理、自动化流程和 Agent 协作如何服务真实工作。课程不把目标限定为知识库问答助手。

## 影响

- 每个阶段都需要同时定义能力目标和项目结果。
- 课程不能只按工具功能排列，需要围绕真实任务组织。
- 社区需要同时维护项目库、能力标准和阶段验收规则。
- 学员可以因为项目需要提前学习某项能力，也可以按照能力模型系统晋级。
- 培训交付和长期陪跑是两个产品阶段，不能在第一期中混为一个承诺。
