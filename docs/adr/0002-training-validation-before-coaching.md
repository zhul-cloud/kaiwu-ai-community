# ADR 0002：先验证培训，再发展长期陪跑

## 状态

已决定

## 背景

社区最终希望持续帮助成员使用 AI 完成工作和项目，但在培训内容、用户需求和招生渠道尚未验证前，直接承诺长期陪跑会扩大交付范围，也会掩盖课程本身的问题。

## 决策

第一期采用 14 天项目制培训作为验证产品。培训以 Claude Code 为主，结合线下、群聊和文档，使用 `llm-wiki` 作为综合案例，要求学员把方法迁移到自己的资料和真实项目中。

长期陪跑作为第二阶段产品，根据付费转化、完课率、项目完成率、迁移效果和继续学习意愿决定服务内容与规模。

## 影响

- 第一阶段优先建设可重复交付的课程、项目和验收标准。
- 陪跑机制先保留为后续设计方向，不作为首期的核心承诺。
- 课程记录必须收集学员卡点、退出原因和项目结果，为后续陪跑产品提供依据。
