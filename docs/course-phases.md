# 四阶段详细课程设计

这份文档把四个大阶段拆成可直接制作讲义、练习和项目的课程单元。每个阶段都遵循：先解决真实问题，再介绍概念；先做最小版本，再增加能力。

## 阶段一：入门——建立 AI 工作环境

### 阶段目标

学员能够安全、独立地使用 Claude Code，从一个清楚的需求开始，完成一次可检查的小任务。

### 适合人群

不会编程或很少接触终端，但愿意用 AI 解决实际工作问题的人。

### 能力范围

- L1 环境使用
- L2 AI 协作起步

### 课程模块

#### 1. AI 工作助手是什么

解决的问题：为什么普通聊天和 Claude Code 的工作方式不同？

内容：

- Claude Code 能读取文件、修改内容和执行任务
- 人仍然负责目标、判断和最终检查
- 用“坐在工作桌旁的助理”解释 AI 工作环境

练习：让 AI 阅读一份资料并整理成一页摘要。

#### 2. 安装、登录和额度

解决的问题：工具为什么装不上、登不上或无法继续使用？

内容：

- 安装 Claude Code
- 注册和登录账号
- 模型、额度和充值
- 代理的作用和基本排查
- 如何确认环境真的可用

练习：完成安装检查表，并保存一份自己的排错记录。

#### 3. 认识工作台

解决的问题：文件、文件夹、终端和项目到底是什么？

内容：

- 用“工作台、抽屉和资料夹”解释目录和文件
- 如何进入正确的项目文件夹
- 如何让 Claude Code 只处理指定范围
- 基本的版本保存和回退意识

练习：创建一个项目文件夹，让 Claude Code 新建、读取和修改三份文件。

#### 4. 第一次完整协作

解决的问题：怎样给 AI 一份能执行的工作说明？

内容：

- 目标、背景、资料、限制和结果
- 如何让 AI 先说明计划再执行
- 如何查看结果并要求改进

练习：完成“资料输入—AI 处理—人工检查—AI 修正”循环。

### 阶段项目

完成一个个人资料整理工具，例如：

- 把一批会议记录整理成行动清单
- 把一组客户资料整理成统一表格
- 把零散笔记整理成主题目录

### 阶段验收

- 能独立启动 Claude Code
- 能说明任务目标和输入资料
- 能让 AI 完成一次文件处理
- 能检查结果并要求修正
- 能保存项目成果和排错记录

### 建议学习时长

7–14 天。第一期 14 天培训的前 5 天覆盖本阶段。

## 阶段二：进阶——让 AI 稳定完成工作

### 阶段目标

学员能够把模糊想法变成清楚的工作流程，并建立一个让 AI 能长期理解的项目空间。

### 能力范围

- L3 任务指挥
- L4 项目上下文和知识管理

### 课程模块

#### 1. 把想法说成任务

解决的问题：为什么同一句话，AI 每次给出的结果不一样？

内容：

- 先说想达成什么结果
- 再说明背景和已有资料
- 说清楚不能做什么
- 规定输出样式和完成标准

练习：把一句“帮我做好这件事”改写成一份可执行工作说明。

#### 2. 把大事拆成小事

解决的问题：AI 一次做太多，结果混乱或中途跑偏怎么办？

内容：

- 用“项目经理给助理分配工作”解释任务拆解
- 识别前后依赖
- 先做最影响结果的一步
- 每一步都设置检查点

练习：把一个真实工作目标拆成 5–8 个可检查步骤。

#### 3. 让 AI 按规则工作

解决的问题：怎样避免每次都重复解释同样的要求？

内容：

- 用“新员工入职手册”解释项目规则
- 项目说明、规则、模板和历史记录
- 哪些资料需要长期保留
- 如何让 AI 先阅读规则再做事

练习：为自己的项目写一份一页纸项目说明。

#### 4. `llm-wiki` 方法迁移

解决的问题：资料越来越多时，怎样让 AI 仍然找得到、看得懂、用得上？

内容：

- 观察 `llm-wiki` 的目录、资料和工作流程
- 把资料按用途而不是按文件格式整理
- 记录项目决策和变更
- 把重复工作写成可复用流程

练习：把个人工作资料迁移到一个简化项目结构。

#### 5. 结果检查与返工

解决的问题：AI 的结果看起来很完整，但可能不准确怎么办？

内容：

- 通过现象看本质：错误来自资料、目标、权限还是检查标准
- 设计检查清单
- 要求 AI 自查、解释和修正
- 保留失败记录

练习：故意给 AI 一份不完整资料，训练发现问题和要求返工。

### 阶段项目

建立个人 AI 工作空间，至少包含：

- 项目说明
- 资料目录
- 规则文件
- 一个固定工作流程
- 一份检查清单
- 一次失败和修正记录

### 阶段验收

- 能把模糊目标拆成步骤
- 能为 AI 提供稳定的项目背景
- 能用规则和模板减少重复沟通
- 能设计结果检查方式
- 能把方法迁移到自己的真实工作

### 建议学习时长

2–4 周。第一期第 6–10 天覆盖本阶段核心内容。

## 阶段三：高阶——让 AI 按流程自己工作

### 阶段目标

学员能够把稳定、重复、有明确标准的工作交给一个或多个 AI 角色执行，并保留人工检查和安全边界。

### 能力范围

- L5 单 Agent 管理
- L6 多 Agent 调度

### 课程模块

#### 1. 从“聊天”到“交给它做”

解决的问题：什么时候可以让 AI 自己连续完成一组工作？

内容：

- 用“把任务交给助理”解释 Agent
- 目标、输入、步骤、工具、边界和输出
- 哪些任务适合交给 Agent
- 哪些任务必须人工确认

练习：画出一个工作流程的输入、步骤和结果。

#### 2. 建立一个单 Agent 工作流

解决的问题：怎样让 AI 每次按同样的步骤做事？

内容：

- 固定工作步骤
- 输入资料检查
- 中间结果保存
- 失败处理
- 最终验收

练习：让 Agent 处理一批同类资料，并输出统一结果。

#### 3. Skills：把工作经验写成手册

解决的问题：怎样把自己会做的事情教给 AI？

内容：

- 用“岗位操作手册”解释 Skill
- Skill 什么时候触发
- Skill 需要哪些资料
- Skill 怎样判断完成

练习：把一个重复工作整理成自己的 Skill。

#### 4. 多 Agent 分工

解决的问题：一个 AI 做不完复杂任务时，怎样合理分工？

内容：

- 用“负责人和几个专员”解释多 Agent
- 任务拆分和角色边界
- 结果汇总和互相检查
- 如何避免多个 Agent 重复做同一件事

练习：将一个研究或内容任务拆成收集、分析、检查三个角色。

#### 5. 给 AI 接上外部工具

解决的问题：AI 需要读取网页、表格、数据库或其他服务怎么办？

内容：

- 用“给助理工具柜和钥匙”解释 MCP
- 工具权限
- 外部资料的来源和可信度
- 连接工具前的安全检查

练习：连接一个低风险工具完成一次真实任务。

### 阶段项目

完成一个可重复运行的 AI 工作流，例如：

- 客户资料研究和跟进建议
- 产品资料整理和发布准备
- 内容选题、资料整理和初稿生成
- 会议资料转行动计划并分派任务

### 阶段验收

- Agent 有明确目标、输入、步骤和输出
- 有权限边界和人工确认点
- 能处理失败和不完整资料
- 工作流可以重复运行
- 多 Agent 之间职责清楚

### 建议学习时长

4–8 周。

## 阶段四：专家——构建自己的 AI 系统

### 阶段目标

学员能够把成熟的工作流发展成可维护、可扩展、可交接的 AI 系统。

### 能力范围

- L7 Agent 系统构建

### 课程模块

#### 1. 设计 Agent 系统

- 从业务结果定义职责
- 设计输入、输出和工具
- 决定一个 Agent 还是多个 Agent
- 设计人工确认和异常处理

#### 2. 开发自己的 Agent 和工具

- 把工作步骤变成可调用能力
- 设计工具输入和输出
- 建立测试样例
- 记录版本和变更

#### 3. 自动运行和团队协作

- 什么时候值得自动运行
- 如何记录执行过程
- 团队如何共享规则、Skills 和资料
- 如何审查 AI 生成的结果

#### 4. 质量、安全和成本

- 识别错误、幻觉和不完整结果
- 权限、敏感资料和外部工具安全
- 上下文和模型成本控制
- 失败后的恢复和回滚

#### 5. 最终系统项目

- 选择一个真实业务流程
- 从最终结果倒推最小版本
- 先手动验证流程
- 再加入 Agent 和自动化
- 用真实数据进行多轮测试
- 交付使用说明、维护说明和改进计划

### 阶段项目

一个可交接的 AI 工作系统，至少包含：

- 清楚的业务目标
- 项目资料和规则
- 一个或多个 Agent
- 工具和权限说明
- 测试样例
- 失败处理方式
- 运行和维护文档

### 阶段验收

- 其他人能够理解并运行系统
- 系统对异常有处理方式
- 关键结果有检查和追溯记录
- 学员能解释为什么这样设计
- 系统可以继续扩展而不必全部重做

### 建议学习时长

8–12 周，适合专题训练、项目制会员或导师陪跑。

## 四阶段之间的晋级方式

学员可以按能力模型顺序学习，也可以因项目需要提前学习某项能力。但进入下一阶段前，必须完成当前阶段的项目验收。

晋级依据是项目结果，不是看完视频或记住术语：

- 阶段一：完成一次可检查的 AI 任务
- 阶段二：建立一个能长期使用的 AI 工作空间
- 阶段三：交付一个可重复运行的 Agent 工作流
- 阶段四：交付一个可维护、可交接的 AI 系统

## 课程制作优先级

第一期先制作阶段一和阶段二的核心内容，并从阶段三选择一个单 Agent 体验项目。每门课先完成“讲义、最小练习、真实项目练习和验收表”，再补充更多案例和高级内容。
