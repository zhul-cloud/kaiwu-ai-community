# 开物学社

> **理解 AI，善用 AI，创造真实价值。**

开物学社是一个面向非技术背景学习者的 AI 实践学习社区。社区帮助成员理解 AI 的工作方式，学会使用 Claude Code、Codex 等工具，完成真实工作和项目，并在实践中提升思考、判断和表达能力。

## 我们要解决的问题

市面上很多 AI 教程停留在概念介绍、工具演示和提示词模板，学习者看完之后仍然不知道如何把 AI 用到自己的工作中。

开物学社采用项目制学习。每个阶段都围绕真实问题、实际操作、项目成果和验收标准展开。

## 学习理念

- **AI 是工具，人是主体。** AI 可以协助执行，人负责目标、判断和价值选择。
- **先解决问题，再理解原理。** 先让学习者看到结果，再解释工具为什么这样工作。
- **知其然，也知其所以然。** 每节课都配有背景知识、历史、原理和思考题。
- **项目驱动，能力晋级。** 学员通过真实项目证明自己掌握了能力。
- **从结果倒推最小路径。** 先明确结果，删除不必要步骤，先完成最小版本，再逐步自动化。
- **用大白话理解复杂问题。** 复杂概念用生活故事、寓言、类比和 ELI5 图示解释。

## 四阶段课程体系

### 阶段一：入门——建立 AI 工作环境

对应能力：环境使用、AI 协作。

学员学习：

- AI 工作助手是什么
- Claude Code 的安装、登录和额度
- 文件、文件夹和项目
- 第一次完整 AI 协作
- 检查结果和要求修正

阶段成果：完成一次“需求—执行—检查—修正”的真实任务。

### 阶段二：进阶——让 AI 稳定完成工作

对应能力：任务指挥、项目上下文和知识管理。

学员学习：

- 把模糊想法变成工作任务
- 抓住主要矛盾，拆解任务
- 用项目规则减少重复沟通
- 用 `llm-wiki` 管理项目资料
- 把重复工作整理成固定流程
- 从实践中发现问题并修正
- 阶段项目设计和交付

阶段成果：建立一个能长期使用的 AI 工作空间。

### 阶段三：高阶——让 AI 按流程自己工作

对应能力：单 Agent 管理、多 Agent 调度。

学员学习：

- Agent 工作方式
- 单 Agent 工作流
- Skills 和可重复工作
- 多 Agent 分工
- MCP 和外部工具

阶段成果：交付一个可重复运行的 AI 工作流。

### 阶段四：专家——构建自己的 AI 系统

对应能力：Agent 系统构建。

学员学习：

- Agent 系统设计
- 自定义 Agent 和工具
- 自动运行和团队协作
- 质量、安全和成本
- AI 系统项目交付

阶段成果：交付一个可维护、可解释、可交接的 AI 工作系统。

## 第一阶段、第二阶段的 14 天训练

第一期是培训验证产品，重点验证课程内容、项目路径和用户需求。建议安排：

- 第 1–4 天：阶段一，完成环境和第一次真实任务
- 第 5–10 天：阶段二，完成任务拆解、项目规则、资料管理和固定流程
- 第 11–14 天：个人项目开发、测试、展示和验收

单次现场课控制在 60–90 分钟：

- 讲解 10–15 分钟
- 教师演示最多 30 分钟
- 学员跟做 20–30 分钟
- 结果检查 5–10 分钟
- 课后完成个人项目练习

## 教学表达标准

每节课都按照以下顺序制作：

1. 真实问题
2. 生活场景或寓言
3. 白话解释
4. 正式概念
5. 最小操作
6. 个人场景练习
7. 结果验收
8. 延伸学习

技术名词第一次出现时，先用人话解释，再标出术语。复杂问题可以借用“抓主要矛盾”“具体问题具体分析”“从实践中来，再回到实践中去”的思路。项目实践使用“从结果倒推最小可行路径”的方法。

## 每节课的延伸学习

每节课结束后提供三层材料：

- **必读：** 10–20 分钟，理解本节课的背景
- **选读：** 历史、原理或案例
- **思考题：** 把知识联系到学员自己的工作

例如：

- AI 工作助手：AI 简史和生成式 AI
- Claude Code：Claude Code 的工作方式和发展历程
- 任务拆解：主要矛盾和实践检验
- `llm-wiki`：知识组织和工作流程记录
- 项目交付：第一性原理、快速迭代和自动化

## 项目方向

学员可以把方法迁移到不同工作场景：

- 内容生产
- 客户研究
- 产品资料处理
- 数据整理
- 工作自动化
- 小型工具和内部应用

## 项目验收

每个项目至少提交：

- 项目目标和真实使用场景
- 输入资料和资料结构
- 项目规则和工作流程
- 输出结果和验收标准
- 失败记录和修正过程
- 下一步改进计划
